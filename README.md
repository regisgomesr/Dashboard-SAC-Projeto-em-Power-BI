# Dashboard-SAC-Projeto-em-Power-BI
Este projeto é meu primeiro dashboard desenvolvido em Power BI, com foco na análise de atendimentos de SAC (Serviço de Atendimento ao Cliente).  O objetivo foi transformar os dados de ocorrências de atendimento em informações visuais que permitam acompanhar indicadores, identificar padrões e analisar o desempenho dos atendimentos ao longo do tempo.
