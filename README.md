# 📊 Dashboard SAC — Primeiro Projeto em Power BI

## Sobre o projeto

Este projeto é meu **primeiro dashboard desenvolvido em Power BI**, com foco na análise de atendimentos de **SAC (Serviço de Atendimento ao Cliente)**.

O objetivo foi transformar os dados de ocorrências de atendimento em informações visuais que permitam acompanhar indicadores, identificar padrões e analisar o desempenho dos atendimentos ao longo do tempo.

### 🗂️ Modelagem dos dados

O projeto utiliza uma estrutura baseada em **modelo dimensional**, composta por:

**Tabela Fato**

* Ocorrências

**Tabelas Dimensão**

* Problema
* Suporte
* Usuário

Essa estrutura permite relacionar as ocorrências às diferentes dimensões e facilitar a análise dos indicadores no Power BI.

### 📈 Principais indicadores e análises

O dashboard apresenta:

* **Total de atendimentos**
* **Retorno médio (dias)**
* **Média de atendimento (minutos)**
* **% de chamados cancelados**
* **Total de atendimentos por ano e mês**
* **Total de atendimentos por problema**
* **Média de atendimento por ano e mês**
* **Total de atendimentos por atendente**

### 🛠️ Tecnologias utilizadas

* Microsoft Power BI
* Modelagem de dados
* Relacionamentos entre tabelas
* DAX
* Visualização de dados

### 🎯 Objetivo do projeto

Este projeto faz parte do meu processo de aprendizado em **Business Intelligence e Análise de Dados**, buscando desenvolver conhecimentos práticos em modelagem de dados, construção de indicadores, DAX e desenvolvimento de dashboards para apoio à tomada de decisão.

Este é meu primeiro projeto em Power BI e representa uma etapa da minha evolução na área de dados.
